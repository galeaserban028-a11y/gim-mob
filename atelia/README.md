# Atelia Build

Proiectare 3D, ofertă și producție (debitare + CNC) într-o singură aplicație, pe mai multe domenii.

- Pornește din motorul GIMMOB Studio (varianta tip ArchiWood), cu brand și date separate (`atelia.*` în localStorage).
- Domenii: Mobilă la comandă (activ) · Ferestre & uși · Design interior · Renovări & construcții · Amenajări exterioare · Mobilier comercial · Confecții metalice (în curând).
- Test gratuit 7 zile (deocamdată doar în browser; plățile reale vin cu Stripe + cont de utilizator).

Link după publicare: https://galeaserban028-a11y.github.io/gim-mob/atelia/
